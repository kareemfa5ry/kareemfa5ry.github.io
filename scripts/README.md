# scripts

Node scripts (the CV generator uses the `yaml` package), run from the repo root on Windows and macOS.

| Script              | What it does                                                                                                                                                                                                                                                                                                                                                                            | Run by                                                      |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| `check_layout.mjs`  | Fails on a source file over 400 lines, a folder with more than 8 loose source files, a `utils`/`helpers`/`misc`/`common` file name, or a lint-silencing comment in `src/`, `scripts/`, `worker/` or the demo skill. It also scans `tests/` for the size and loose-file caps. Prints `path: reason` per violation, or `layout ok`.                                                       | `npm run check:layout` (part of `npm run check`)            |
| `guard_git.mjs`     | Claude Code `PreToolUse` hook on Bash: blocks `git commit --no-verify` / `-n` and `git push --force` / `-f` with exit 2.                                                                                                                                                                                                                                                                | `.claude/settings.json`                                     |
| `check_file.mjs`    | Claude Code `PostToolUse` hook on Edit/Write: checks the one edited file (eslint, prettier, 400-line and 8-loose-file caps, no lint silencing) via `check_layout.mjs`; prints `fable-code: ...` lines and exits 2, or exits 0 silently. Advisory, never edits.                                                                                                                          | `.claude/settings.json`                                     |
| `check_pr_name.mjs` | Fails when a PR's number, title (`NN: <feature>`) and branch (`feature/NN-short-name`, `chore/...`) disagree, from `PR_NUMBER`, `PR_TITLE`, `PR_BRANCH`. Without `PR_NUMBER` only the branch format is checked (`main` and a detached HEAD pass). Prints one line per problem, or `pr name ok`.                                                                                         | CI `check` job on pull requests; `.githooks/pre-push`       |
| `cv/generate.mjs`   | Writes `cv/*.tex` (both CVs) from the front matter in `src/content/` and the `src/site/*.ts` modules. `--check` regenerates in memory and exits 1 with `cv: <file> stale, run npm run cv:generate`, or `cv: <pdf> not rebuilt, run npm run cv:pdf` when a .tex hash differs from `cv/built-from.json`. A skill id missing from `src/content/skills` is skipped with a one-line warning. | `npm run cv:generate`; `--check` is part of `npm run check` |
| `cv/latex.mjs`      | LaTeX escaping (special characters, a small Unicode map, an error on any other non-ASCII character) and the section writers used by `generate.mjs`.                                                                                                                                                                                                                                     | `generate.mjs`; `tests/unit/cv_latex.test.mjs`              |
| `cv/build_pdf.mjs`  | Runs `pdflatex` twice per CV (found on PATH, or `/Library/TeX/texbin` on macOS; install hint when missing) with the phone number from the ignored `cv/phone.txt` (loud warning, built without it when missing), copies the PDFs to `public/assets/cv/` and rewrites `cv/built-from.json` with the sha256 of each .tex.                                                                  | `npm run cv:pdf`                                            |
